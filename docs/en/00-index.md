# Documentation index

This directory documents a test rig: a docker-compose environment that runs the
official Gematik ISiK test suite against an InterSystems IRIS for Health FHIR
repository, for ISiK Stufe 3 and Stufe 5.

Everything here is authored English documentation. It describes the rig, not the
result of any particular round — a round's own result is in
`reports/<run-id>/analysis/results.md` (cited, regulatory),
`reports/<run-id>/GAP-ANALYSIS.md` (interpreted, for product developers) and its
annex `reports/<run-id>/CASE-EVIDENCE.md` (one clause per failing case, with the
exchange verbatim), all generated by `make report`.

German-language regulatory documentation, for the *Bestätigungsverfahren*, is in
[`../de/`](../de/). It is deliberately not a translation: it covers the procedure
and the results, in the language the ISiK specification and its inspectors use.

Generated documentation — the test-data requirement tables extracted from the
pinned test suite's own feature files — is in [`generated/`](generated/) and is
rewritten by `make packages`. It is not committed, for the reason its own README
gives.

## Conventions

**Language.** Source comments, technical specification and description are
English. German is used for regulatory documentation and wherever an ISiK term is
quoted; ISiK's own specification is German-only on purpose, and translating a
requirement would put an interpretation between the specification and the test.

**Citations.** A claim about the test suite cites a feature file and line
(`Stufe5/Basis/Encounter-Read.feature:52`), relative to the suite's own
`features/` root. A claim about a result cites a path inside the official report
archive. A claim about this rig cites a file and line in this repository.

**Versions.** Every version in this documentation is the one pinned in
`.env.example`. A round's actual versions, with image digests, are in
`.env.resolved` and are copied into each evidence bundle as
`provenance/env.resolved.txt`.
